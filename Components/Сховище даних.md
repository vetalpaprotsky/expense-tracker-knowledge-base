# Сховище даних

**Сховище даних** — шар збереження на SQLite (`sqlite3`) з параметризованими запитами. Таблиці: expenses, categories (та budgets у майбутньому). Індекс за датою прискорює вибірки за період.
Надає CRUD для [[Витрата|витрат]] і вибірки за [[Категорія витрат|категорією]] та діапазоном дат для [[Модуль звітності]].
