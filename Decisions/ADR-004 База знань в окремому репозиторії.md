# ADR-004 База знань в окремому репозиторії

## Контекст
Агент IDE відкриває лише репозиторій застосунку; потрібно, щоб знання про застосунок були доступні лише через контрольований канал.

## Рішення
Зберігати vault Obsidian у власному git-репозиторії, поза робочою директорією IDE. Доступ — лише через MCP-сервер конектора (ingest_note, get_note, search_notes).

## Альтернативи
Директорія `kb/` у репозиторії застосунку (агент міг би читати й змінювати її в обхід конектора).

## Наслідки
Потрібен окремий MCP-сервер; синхронізація через git pull/push; індекс RAG є похідним артефактом.
