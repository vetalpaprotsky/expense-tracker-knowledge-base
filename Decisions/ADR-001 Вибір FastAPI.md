# ADR-001 Вибір FastAPI

## Контекст
Потрібен веб-фреймворк для невеликого REST API з автоматичною валідацією та документацією.

## Рішення
Використати **FastAPI**: типізовані схеми [[Pydantic-модель|Pydantic]], автоматична OpenAPI-документація, `TestClient` для тестів.

## Альтернативи
Flask (немає вбудованої валідації), Django REST Framework (надмірно важкий для задачі).

## Наслідки
Залежність від Pydantic v2; [[API-шар]] описується декларативно.
