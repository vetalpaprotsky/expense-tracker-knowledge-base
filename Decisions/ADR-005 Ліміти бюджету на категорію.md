# ADR-005 Ліміти бюджету на категорію

## Контекст
Для контролю витрат потрібні ліміти (FR-6). Можливі ліміти на загальну суму або на кожну категорію.

## Рішення
Задавати [[Місячний бюджет]] окремо для кожної [[Категорія витрат|категорії]]; загальний ліміт не вводити.

## Альтернативи
Єдиний загальний ліміт на місяць (менш інформативний), ліміти на тиждень (ускладнює звіт).

## Наслідки
Таблиця budgets із ключем за категорією; [[Перевищення бюджету]] обчислюється для кожної категорії окремо.
